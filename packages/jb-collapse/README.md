# jb-collapse

Accessible animated disclosure Web Component used by JB form interfaces.

```html
<script type="module" src="jb-collapse/define"></script>
<jb-collapse open>
  <span slot="title">Settings</span>
  <div>Panel content</div>
</jb-collapse>
```

React applications can import `JBCollapse` from `jb-collapse/react`.
